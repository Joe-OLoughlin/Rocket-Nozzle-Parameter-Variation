# Rocket Nozzle Parameter Variation

A MATLAB tool for generating complete converging-diverging rocket nozzle contours from four key design parameters. The convergent and throat sections are polynomial fits; the divergent section is generated by an original blend function developed for this work. The geometry is plotted for inspection and exported as coordinate files ready to import into CAD (SolidWorks) and on to CFD (STAR-CCM+).

Developed as part of my Master's thesis on nozzle design and CFD analysis at the University of Limerick.

## The four key parameters

The study varies four geometric parameters, set at the top of `Nozzle_Geometry_Generation_Script.m`:

| | Parameter | Variable | Study range |
|---|---|---|---|
| A | Expansion ratio (exit area / throat area) | `expansion_ratio` | 150 to 350 |
| B | Divergent start angle | `div_start_deg` | 30 to 40 deg |
| C | Divergent length | `L_div` | 3.5 to 5.5 m |
| D | Divergent exit angle | `div_exit_deg` | 0 to 8 deg |

A fifth input, the throat radius `r_th`, scales the whole nozzle. The remaining geometry (inlet radius, convergent and throat lengths, convergent angle) is fixed relative to it.

Sweeping A to D produces the family of nozzle geometries this repo is named for, with coordinate files named in the pattern `A<expansion ratio>_Ds<start angle>_De<exit angle>`.

## The blend function (original work)

Analytical approaches such as the Method of Characteristics or the Mach-Area relation produce theoretical nozzle shapes, but they require predefined exit flow properties and offer limited geometric flexibility. The divergent section here is instead generated by a custom blend function, created to support geometry-driven performance analysis. It can be applied to any nozzle, irrespective of size, parameters, or use case.

The wall radius over the divergent length is:

$$r(x) = r_{start} + (r_{exit} - r_{start})\left[(1 - t_{exit} L_{div})\left(1 - \left(1 - \frac{x}{L_{div}}\right)^{n}\right) + (t_{exit} L_{div})\frac{x}{L_{div}}\right]$$

where the exponent and the normalised start and exit slopes are:

$$n = 1 + \frac{s_0 L_{div} - 1}{1 - t_{exit} L_{div}}, \qquad s_0 = \frac{\tan(\theta_{start})}{r_{exit} - r_{start}}, \qquad t_{exit} = \frac{\tan(\theta_{exit})}{r_{exit} - r_{start}}$$

In words: the shape is a weighted mix of a power-law curve and a straight line. The exit angle sets the weighting, and the start angle sets the exponent `n`, so the curve leaves the throat at exactly the chosen start angle and arrives at the exit radius at exactly the chosen exit angle. Because the second derivative of the blend cannot change sign (for valid parameter combinations), the expansion is monotonic with no inflection points, which helps maintain flow attachment and numerical stability in CFD. The script checks this on every run and warns if a parameter combination would produce an inflection.

## The other two sections

| Section | Curve | Constraints |
|---|---|---|
| Convergent | 4th-degree polynomial | Inlet radius with zero slope and curvature at the inlet; chosen radius and wall angle at the throat entry |
| Throat | Constrained 7th-degree polynomial | Position, slope, and curvature matched to the convergent section at entry; exact throat radius `r_th` with zero slope at an adjustable location `x_throat_min`; radius, start angle, and zero curvature at the hand-off to the divergent section |

Slope and curvature are matched at both junctions, so the full contour is smooth from inlet to exit and the throat minimum (and therefore the expansion ratio) is always exact.

## How to use it

1. Open `Nozzle_Geometry_Generation_Script.m` in MATLAB.
2. Set parameters A to D (and `r_th` if rescaling) at the top.
3. Run. You get:
   - A plot of the contour with the three sections colour-coded and the parameter set in the title.
   - An inflection point check printed to the command window.
   - Three tab-delimited coordinate files (x, y, z columns, z = 0) written to your `Downloads` folder: `convergent_section.txt`, `throat_section.txt`, `divergent_section.txt`.

The `.txt` files import into SolidWorks via **Insert > Curve > Curve Through XYZ Points**. Import the three curves, close and revolve the profile, then export as Parasolid (`.x_t`) for STAR-CCM+.

## Other files in this repo

- `Final_Nozzle_Generation_Script.mlx` - an earlier variant of the generator in live script form. Same convergent and throat construction, but its divergent section uses a 5th-degree polynomial fit instead of the blend function (its outputs carry the `_BC_Rao` naming).
- `Final_Macro.java` / `Final_Total_Macro.java` - recorded Simcenter STAR-CCM+ (v19.02) macros from the CFD side of the study: mesh surface controls, scene setup, and the full case setup used to run the nozzle simulations. They assume a simulation whose part is named `Nozzle` with `Inlet`, `Freestream`, and `Symmetry` surfaces, so treat them as a workflow reference rather than click-and-run scripts.
